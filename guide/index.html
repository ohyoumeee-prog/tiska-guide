굿즈 주문 제작 가이드 — 문의부터 납품까지

2026년 11월 27일 기준 · 주식회사 티스카

한 줄 답변

티스카의 굿즈 주문 제작은 메인 발주 500개부터 진행하며, 문의 → 시안 → 견적 → 샘플 → 양산 → 납품의 6단계로 이어집니다. 디자인 확정 후 샘플 1일~2주, 승인 샘플 기준 양산 7~20일이 표준이고, 기간은 품목군마다 다릅니다.

시작 전에 확인할 4가지

  • ① 일정 여유샘플·양산 표준 기간에 시안 수정, 검품, 배송 기간의 여유를 더해 행사일에서 거꾸로 계산합니다. 행사일이 정해져 있다면 행사일 역산 일정 계산기로 디자인 확정 마감일과 문의 권장일을 먼저 확인해 주세요.
  • ② 디자인 파일로고·캐릭터 파일은 AI·PDF·PSD 원본이 가장 좋습니다. JPG·PNG만 있어도 디자인팀이 도안 작업을 지원합니다. 티스카는 디자인과 생산을 함께 진행하며, 디자인 시안은 무료입니다.
  • ③ 사용 권한캐릭터, 아티스트, 브랜드 로고처럼 권리가 있는 디자인은 사용 권한을 가진 담당자가 의뢰해 주셔야 합니다. 소속사·라이선스 담당 부서의 확인이 필요한 경우 승인 일정도 함께 고려해 주세요.
  • ④ 승인 샘플 기준 양산양산은 승인된 샘플을 기준으로 진행합니다. 승인 뒤에 색상·크기·구성을 바꾸면 샘플을 다시 만들어야 할 수 있어 일정에 영향을 줍니다. 승인 전에 색상, 크기, 로고 위치, 부자재, 포장을 한 번에 정리해 확인해 주세요.

6단계 상세

각 단계에서 티스카가 하는 일과 담당자가 준비할 것을 정리했습니다. 숫자로 안내하는 기간은 샘플과 양산뿐이며, 나머지 단계의 기간은 품목·수량 확정 후 안내합니다.

  1. 1:1 미팅·문의 접수
    하는 일
    품목·수량·예산·납기를 확인하고 전담 PM이 배정됩니다.
    담당자가 준비할 것
    품목 목록, 수량과 사이즈, 예산과 용도, 사용 일정
    소요 기간
    품목·수량 확정 후 안내
  2. 기획·디자인(무료 시안)
    하는 일
    내부 디자인팀이 레퍼런스를 바탕으로 무료 시안을 만듭니다.
    담당자가 준비할 것
    로고·캐릭터 원본 파일(AI·PDF·PSD), 원하는 느낌의 레퍼런스 이미지
    소요 기간
    품목·수량 확정 후 안내
  3. 사양 설계·견적(수량 구간별 단가)
    하는 일
    소재·가공·규격·부자재를 정하고 수량 구간별 단가로 견적을 드립니다.
    담당자가 준비할 것
    검토할 수량 구간, 포장 방식, 납품 장소
    소요 기간
    품목·수량 확정 후 안내
  4. 디자인 확정·샘플 제작
    하는 일
    확정된 디자인으로 실물 샘플(프로토타입)을 만들어 색상·크기·마감을 확인합니다.
    담당자가 준비할 것
    승인 전 확인 항목(색상, 크기, 로고 위치, 부자재, 포장)
    소요 기간
    샘플 1일~2주(품목군별)
  5. 양산(승인 샘플 기준, QA/QC)
    하는 일
    승인된 샘플을 기준으로 생산하고 QA/QC를 거칩니다.
    담당자가 준비할 것
    승인 샘플 기준 유지(승인 뒤 변경은 일정에 영향)
    소요 기간
    양산 7~20일(품목군별)
  6. 검품·납품·사후관리
    하는 일
    검품 후 납품하고, 추가 생산 같은 사후 관리까지 전담 PM이 이어서 맡습니다.
    담당자가 준비할 것
    납품 주소, 받는 분, 분배·포장 요청
    소요 기간
    품목·수량 확정 후 안내

품목군별 최소 수량·표준 기간

모든 품목군은 메인 발주 500개부터 제작합니다. 수량이 늘수록 개당 단가가 내려가며, 단가는 도안 복잡도·가공 방식에 따라 견적 단계에서 수량 구간별로 안내합니다. 기간은 디자인 확정 시점부터의 표준 소요 기간입니다.

문의 때 알려 주시면 좋은 4가지

  1. 품목: 만들고 싶은 굿즈 종류입니다. 여러 개라면 목록으로 보내 주시고, 비슷한 제작 사례 페이지 주소가 있으면 함께 알려 주세요.
  2. 수량과 사이즈: 품목별 수량과 원하는 크기입니다. 메인 발주는 500개부터이며, 수량 구간을 두세 가지로 알려 주시면 구간별 단가를 비교해 드립니다.
  3. 예산과 용도: 판매용, 증정용·사은품, 행사 배포, 임직원 웰컴키트 등 용도와 대략의 예산 범위입니다. 용도에 맞는 소재와 포장을 제안하는 데 씁니다.
  4. 사용 일정: 행사일, 공연일, 입사일처럼 굿즈가 필요한 날짜입니다. 납품 장소와 분배 방식이 정해져 있다면 함께 알려 주세요.
