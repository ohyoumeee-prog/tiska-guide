## 한 줄 답변
뷰티 브랜드 멤버십·VIP 키트는 메인 발주 500개부터 품목별로 제작하며, 외함(싸바리 패키지)·파우치·미러 키링·카드지갑 4가지로 구성을 잡으면 정리가 쉽습니다. 패키지·세트류는 샘플 1주·양산 14일, 파우치는 샘플 1주·양산 20일, 아크릴 키링류는 샘플 1일·양산 7일입니다. 가장 긴 품목에 맞춰 일정을 역산하고 전담 PM이 품목별 일정을 하나로 묶어 관리합니다.

## 1. 키트 구성 4가지 비교
| 구성 | 참고 공개 사례 | 소재·가공 | 품목군 | 샘플·양산 |
|---|---|---|---|---|
| 외함 | 타이틀리스트(Titleist) 서랍형 기프트 패키지 | 싸바리 외함, 서랍 구조재 / 2층 서랍 설계, 손잡이 | 패키지·세트류 | 1주·14일 |
| 키링 | 세븐틴(SEVENTEEN) x 무직타이거 아크릴 미러 키링 | 아크릴, 거울 시트 / 모서리 라운딩, 후면 거울 합지 | 아크릴·키링류 | 1일·7일 |
| 카드지갑 | 타이틀리스트(Titleist) 원터치 명함 카드지갑 | 알루미늄 또는 레자 / 원터치 기구 조립, 각인 또는 인쇄 | 문구·인쇄류 | 1주·14일 |
| 합포장 | 타이틀리스트(Titleist) 골프 웰컴키트 | 상하 싸바리 박스, 내부 폼 / 품목별 제작 후 합포장, 외함 인쇄 | 패키지·세트류 | 1주·14일 |

## 2. 사례에서 읽히는 구성 힌트
타이틀리스트 서랍형 기프트 패키지는 2층 서랍 설계와 손잡이로 만든 외함으로, VIP 선물·기업 명절 선물·브랜드 언박싱 패키지 용도로 공개된 사례입니다. 세븐틴 x 무직타이거 아크릴 미러 키링은 팬클럽 키트·콜라보 MD·뷰티 브랜드 사은품 용도로 소개되어, 멤버십 키트에 넣는 거울 굿즈를 구상할 때 참고가 됩니다. 타이틀리스트 골프 웰컴키트는 품목별 제작 후 합포장하는 구조여서, 여러 품목을 한 외함에 모으는 방식을 이해하기 좋습니다. 공개 사례에 화장품 브랜드는 없으며, 뷰티 브랜드 사은품 용도로 소개된 사례까지만 인용합니다.

멤버십 키트는 받는 분이 처음 상자를 여는 순간이 브랜드 인상으로 남기 때문에, 외함의 인쇄와 내부 배치를 먼저 정하고 그 안에 담을 품목을 고르는 순서를 권합니다. 외함을 먼저 확정하면 파우치·키링·카드지갑의 규격이 정해져 내부 구조재 설계가 이어지고, 합포장 단계에서 규격이 맞지 않는 일을 줄일 수 있습니다. 반대로 구성품이 먼저 정해져 있다면 구성품 치수를 알려 주세요. 치수에 맞춘 맞춤 재단으로 외함을 설계합니다.

## 3. 등급별 구성안 짜기
| 구분 | 일반 멤버십 | VIP |
|---|---|---|
| 구성 | 미러 키링 + 카드지갑 | 외함 + 파우치 + 키링 |
| 포장 | 개별 포장 | 외함 합포장 |
| 사양 포인트 | 로고 인쇄·각인 | 외함 인쇄, 내부 구조재 |
| 기간 기준 | 짧은 품목 기준 | 가장 긴 품목 기준 |

등급마다 구성품을 다르게 하려면 시안 단계에서 종류 수를 먼저 정해 두세요. 품목마다 메인 발주 500개부터 수량을 정할 수 있고, 수량 구간별 단가는 견적 시 안내합니다.

## 4. 키트 일정 역산 순서
1. 키트 발송일(수령일)을 정하고, 합포장·검품 여유를 권장치로 잡습니다.
2. 가장 긴 품목(파우치 양산 20일)부터 시작일을 거꾸로 계산합니다.
3. 외함은 구성품 규격이 확정된 뒤 내부 구조재 설계를 시작합니다.
4. 미러 키링처럼 짧은 품목(샘플 1일·양산 7일)은 뒤에 배치합니다.

기간은 FACTS의 품목군 표 기준이며, 합포장·검품 기간은 (표준 기간을 더한 권장치)로 별도 여유를 두세요. 견적 요청서에 적을 항목은 견적 요청서 작성법 글에 정리했습니다. 티스카는 샘플 승인 뒤 승인 샘플 기준으로 QA/QC를 거쳐 양산하고, 500개 미만의 소량이 필요하면 자체 소량 제작 쇼핑몰 나도메이커(nadomaker.com)에서 제작할 수 있습니다.
