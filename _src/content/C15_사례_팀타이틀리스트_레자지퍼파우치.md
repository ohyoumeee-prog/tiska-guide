## 한 줄 답변
티스카는 팀 타이틀리스트(Team Titleist)의 레자 지퍼 파우치를 융털 안감을 붙인 구성으로 제작했으며, 같은 사양은 메인 발주 500개부터 진행합니다. 이 품목군은 샘플 1주, 양산 20일이 걸립니다. 골프 대회 기념품과 VIP 키트 구성품으로 만든 사양이지만, 연말 VIP 선물이나 시즌 사은품용 화장품 파우치를 같은 소재로 준비하는 담당자에게도 참고가 됩니다.

## 1. 제작 정보
| 항목 | 내용 |
|---|---|
| 클라이언트 | 팀 타이틀리스트(Team Titleist) |
| 품목 | 레자 지퍼 파우치 |
| 소재 | 레자 겉감, 융털 안감 |
| 가공 | 레자 재단, 안감 접합, 지퍼 봉제, 로고 인쇄 |
| 용도 | 골프 대회 기념품, 기업 선물, VIP 키트 구성품 |
| 최소 수량 | 메인 발주 500개부터 |
| 샘플·양산 | 샘플 1주 · 양산 20일(가방·파우치류) |

## 2. 제작 포인트
- 레자를 재단해 겉감으로 쓰고 융털 안감을 접합해, 겉은 가죽 느낌을 살리고 안쪽은 부드럽게 마감했습니다.
- 지퍼 봉제로 여닫는 구조라 소지품을 넣고 닫아 두기 좋습니다.
- 로고 인쇄로 브랜드를 드러냈고, 인쇄 색과 위치는 샘플 단계에서 실물로 확인한 뒤 승인 샘플 기준으로 양산합니다.
- 기념품·기업 선물·VIP 키트 구성품을 한 사양으로 함께 준비할 수 있습니다.

## 3. 이런 곳에 어울립니다
- VIP 키트 구성품: 박스 안에 다른 구성품과 함께 넣어 고급스러운 인상을 더합니다.
- 기업 선물로 건넬 때는 로고만 바꿔도 일상에서 쓰는 실용품이 됩니다.
- 화장품 파우치를 레자로 만들려는 담당자라면 겉감·안감 조합과 지퍼 마감을 그대로 참고할 만합니다.

## 4. 같은 사양으로 만들려면
진행 순서는 문의 접수 → 기획·디자인(무료 시안) → 사양 설계·견적 → 디자인 확정·샘플 제작 → 양산(승인 샘플 기준) → 검품·납품입니다. 가방·파우치류는 샘플 1주, 양산 20일이 표준이라 디자인 확정 뒤 약 4주를 기본 일정으로 잡습니다.

| 단계 | 기간 | 디자인 확정일 기준 |
|---|---|---|
| 샘플 제작·승인 | 1주 | 확정 후 1주 |
| 양산 | 20일 | 확정 후 약 4주 |
| 검품·배송 | 권장 여유 | 별도로 더함 |

시안 수정과 검품·배송 여유까지 고려하면 희망 납품일 7주 전에는 문의하시는 것을 권합니다(표준 기간을 더한 권장치). 로고는 AI·PDF 원본이 좋고, JPG·PNG만 있어도 디자인팀이 도안 작업을 지원합니다. 파일 준비는 '굿즈 제작 디자인 파일, 어떻게 준비해야 할까?' 글을, 품목별 수량 기준은 '에코백·키링·뱃지 주문 제작 최소 수량, 몇 개부터일까?' 글을 참고하세요.

## 자주 묻는 질문
**Q. 로고만 바꿔 같은 사양으로 만들 수 있나요?**
가능합니다. 레자 겉감·융털 안감·지퍼 봉제 구성은 유지하고 로고 인쇄만 바꿔 진행하며, 담을 물건에 맞춰 규격도 조정합니다.

**Q. 수량과 단가는 어떻게 안내되나요?**
메인 발주 500개부터 진행하고, 단가는 규격·인쇄 방식에 따라 달라져 견적 시 수량 구간별로 안내합니다. 500개 미만의 소량이 필요하면 자체 소량 제작 쇼핑몰 나도메이커(nadomaker.com)에서 제작할 수 있습니다.

**Q. 연말 사은품 일정에 맞추려면 기간이 얼마나 필요한가요?**
가방·파우치류는 샘플 1주, 양산 20일이 표준입니다. 디자인 확정 뒤 약 4주에 검품·배송 여유를 더해 희망 납품일에서 역산해 문의하시면 전담 PM이 일정을 함께 잡습니다.
