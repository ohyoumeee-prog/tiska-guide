# 굿즈 제작 디자인 파일, 어떻게 준비해야 할까? (로고만 있을 때 포함)

_출처: https://ohyoumeee-prog.github.io/tiska-guide/posts/design-file-preparation.html · 게시 2026-11-05 · 주식회사 티스카_

## 한 줄 답변
굿즈 제작용 디자인 파일은 AI·PDF·PSD 원본(벡터 또는 레이어가 살아 있는 파일)이 가장 좋지만, 로고 JPG·PNG만 있어도 티스카 디자인팀이 도안 작업을 지원합니다. 디자인 시안은 무료로 제공하며, 디자인은 생산과 함께 하나의 프로젝트로 진행합니다. 티스카의 메인 발주는 500개부터 진행합니다.

## 1. 파일 형식별 가능 여부
| 보유 파일 | 제작 가능 여부 | 진행 방식 |
|---|---|---|
| AI, PDF(벡터), PSD 원본 | 바로 가능 | 사양에 맞춰 도안 배치·색 분리 후 시안 |
| 고해상도 PNG, JPG(로고만) | 가능 | 디자인팀이 벡터로 다시 그리거나 도안을 재작업한 뒤 시안 제공 |
| 저해상도 이미지, 화면 캡처 | 가능(재작업 필요) | 원본에 가깝게 재작업, 색상·형태는 담당자 확인 필요 |
| 손그림, 아이디어 메모, 레퍼런스 사진 | 가능 | 기획·디자인 단계에서 디자인팀이 시안을 새로 제안 |
| 아티스트·캐릭터 IP 아트워크 | 권리자 승인 필요 | 승인 주체 확인 후 시안·샘플 진행 |

모든 행은 메인 발주 500개부터 기준입니다.

## 2. 가공 방식별로 디자인에서 확인할 것
- 실크 인쇄: 색 수가 단가에 영향을 줍니다. 로고 색 수를 최소한(단색 또는 소수 색)으로 정리할 수 있는지 확인하세요. 그라데이션은 전사·UV 인쇄 쪽이 맞습니다.
- 전사·승화전사, UV 인쇄: 풀컬러·사진·그라데이션 표현에 적합합니다. 원본 해상도가 높을수록 결과가 좋습니다.
- 자수: 가는 선과 작은 글자는 굵고 단순한 형태로 정리할수록 재현도가 높아집니다. 로고를 단순화한 자수용 버전이 있으면 좋고, 없으면 디자인팀이 만듭니다.
- 레이저 각인: 단색으로 표현되므로 색 정보는 사라지고 형태만 남습니다. 선이 명확한 벡터 로고가 적합합니다.
- 금속 뱃지(아연합금 주조·도금·에폭시): 색 영역이 금속 선으로 구분되므로, 색 경계가 분명한 디자인이 재현도가 높습니다. 도금 색(무광·유광·흑니켈·금장)을 함께 정합니다.
- 아크릴(도무송 재단·UV 인쇄): 재단선과 인쇄 영역을 분리해 설계합니다. 고리 위치를 미리 정해 두면 시안이 빨라집니다.
- 실리콘·PVC(금형 성형): 형태 자체를 설계하므로 정면·측면 도안이 필요합니다. 평면 로고만 있어도 디자인팀이 입체 도안을 제안합니다.

## 3. 시안 확정 전 체크리스트
1. 브랜드 컬러 값(팬톤 또는 CMYK)이 있는지. 없으면 샘플에서 실물 색을 확인해 정합니다.
2. 로고 사용 규정(최소 크기, 여백, 금지 조합)이 있는지.
3. 품목별 인쇄 위치와 크기(예: 에코백 앞면 중앙, 뱃지 전체).
4. 글자가 들어가면 서체 저작권과 외곽선 처리 여부.
5. 아티스트·캐릭터·단체 로고 등 타인의 IP는 사용 승인 주체와 범위.
6. 포장·라벨에 들어갈 표기(단체명, 캠페인명, 주의 문구).

## 4. 진행 순서와 기간
디자인은 전체 6단계 중 ② 기획·디자인과 ④ 디자인 확정 단계에 해당합니다. 시안 확정 후 샘플(품목에 따라 1일~2주)을 만들고, 샘플 승인 후 양산(7~20일)에 들어갑니다. 디자인 수정이 많이 예상되면 그만큼 앞 단계 기간을 여유 있게 잡으세요.

## 자주 묻는 질문
**Q. 디자인 시안은 몇 번까지 수정되나요?**
시안은 디자인 확정 전까지 전담 PM과 조율하며 수정합니다. 수정 횟수와 범위는 프로젝트 성격에 따라 미팅에서 안내합니다.

**Q. 디자인만 맡길 수 있나요?**
디자인은 생산과 함께 하나의 프로젝트로 진행합니다. 디자인과 생산을 함께 진행하는 조건에서 시안을 무료로 제공합니다. 티스카의 메인 발주는 500개부터 진행합니다. 500개 미만의 소량은 자체 소량 제작 쇼핑몰 나도메이커(nadomaker.com)에서 제작할 수 있습니다.

**Q. 어떤 형식으로 보내면 되나요?**
AI·PDF·PSD 원본을 이메일(ttiska@naver.com)로 보내 주시면 가장 빠릅니다. JPG·PNG만 있어도 보내 주시면 디자인팀이 확인 후 진행 방식을 안내합니다.
