# 굿즈 샘플 승인 전 확인할 5가지, 양산 전에 무엇을 점검할까?

_출처: https://ohyoumeee-prog.github.io/tiska-guide/posts/sample-approval-checklist.html · 게시 2026-11-26 · 주식회사 티스카_

## 한 줄 답변
메인 발주 500개부터 진행하는 티스카의 주문 제작은 승인된 샘플을 기준으로 양산합니다. 샘플은 품목군에 따라 1일~2주 걸리고 양산은 7~20일이므로, 샘플에서 사양·색·크기·마감·구성 5가지를 확인하고 승인하는 것이 핵심입니다. 승인 이후의 변경은 일정에 영향을 주기 때문에 승인 전에 의견을 모두 전달하는 것을 권장합니다.

## 1. 샘플 승인 5가지 체크
| 항목 | 확인 내용 | 예시 |
|---|---|---|
| 사양 | 소재·두께·가공이 견적서와 같은지 | 아연합금 볼마커의 무광 도금, 에폭시 인쇄 |
| 색 | 도안 색과 실물 색의 차이 | 도금 색, 인쇄 색 |
| 크기 | 규격과 비율이 의도와 맞는지 | 키링 크기, 파우치 규격 |
| 마감 | 모서리·접합·봉제·로고 면 상태 | 접합부, 손잡이 봉제 |
| 구성 | 부자재·포장·세트 구성이 맞는지 | 링, 체인, 박스 |

## 2. 품목군별 샘플 기간
| 품목군 | 샘플 | 양산 |
|---|---|---|
| 아크릴·키링류 | 1일 | 7일 |
| 금속·주얼리류, 가방·파우치류, 패브릭·의류류 | 1주 | 20일 |
| 패키지·세트류, 문구·인쇄류 | 1주 | 14일 |
| 기타(텀블러·우산 등) | 2주 | 20일 |

샘플이 짧은 아크릴·키링류는 실물 확인을 여러 번 거치기 좋습니다. 샘플 기간이 긴 품목은 수정 회차를 계획에 넣어 두는 것이 좋습니다.

## 3. 공개 사례로 보는 확인 포인트
타이틀리스트 골프 볼마커 2종 사례는 아연합금 소재에 에폭시 인쇄 또는 음각, 자석 유무를 선택하는 사양입니다. 이런 품목은 로고 면 표현 방식과 자석 유무를 샘플에서 확인합니다. 굿이어타이어 에코백 사례는 면 캔버스에 실크 또는 전사 인쇄, 손잡이 봉제 사양이라 인쇄 위치와 손잡이 마감이 확인 포인트입니다. 사양이 같아 보여도 용도에 따라 보는 곳이 달라집니다.

## 4. 승인 이후 절차
1. 샘플 승인 의사를 전담 PM에게 전달합니다.
2. 승인된 샘플을 기준으로 양산에 들어갑니다.
3. 양산 중 QA/QC를 거칩니다.
4. 검품 후 납품하고 사후관리를 이어갑니다.

승인 전에는 수정 요청이 반영되지만, 승인 후 사양을 바꾸면 샘플부터 다시 진행해야 할 수 있습니다. 일정에 여유가 없다면 승인 전 확인 항목을 미리 목록으로 정리해 한 번에 전달하는 방법이 좋습니다. 도안 수정은 샘플 제작 전에 마치고, 도안은 AI·PDF·PSD 원본이 가장 좋습니다.

## 5. 샘플 전에 준비하면 좋은 것
샘플이 빨리 나오려면 시작 단계의 정보가 정리되어 있어야 합니다. 품목, 수량, 납기, 용도, 도안, 포장 정보를 견적 요청에 담으면 사양 설계 단계에서 소재와 가공, 규격, 부자재가 한 번에 정리됩니다. 승인 기준이 되는 항목을 미리 정해 두는 것도 좋은 방법입니다. 예를 들어 색은 어느 정도의 차이까지 괜찮은지, 크기는 어느 규격이 필요한지를 담당자가 먼저 정리해 두면 샘플을 받았을 때 판단이 빨라집니다. 여러 명이 확인해야 하는 경우에는 의견을 한 곳에 모아 전달해 주시면 수정 회차를 줄일 수 있습니다. 티스카는 자체 공장과 광저우·이우 생산 네트워크를 함께 운영하며, 어느 쪽에서 만들든 승인 샘플 기준으로 양산하고 QA/QC와 검품, 납품까지 전담 PM이 이어서 관리합니다.
승인이 끝난 뒤에는 양산 일정이 시작되므로, 샘플을 받은 날 바로 확인 항목을 하나씩 체크하고 내부 의견을 모아 답변하는 흐름을 권장합니다. 승인 여부가 늦어지면 그만큼 납품 일정도 뒤로 밀릴 수 있어, 샘플 도착 전에 승인 담당자와 확인 일정을 정해 두면 좋습니다.

여러 품목을 한 번에 진행할 때는 품목별로 샘플 기간이 다르므로, 가장 긴 샘플 기간을 기준으로 승인 일정을 잡으면 전체 계획이 안정됩니다. 같은 세트 안의 품목은 승인 시점을 맞춰 두면 양산 시작도 가지런해집니다.

## 자주 묻는 질문
**Q. 샘플은 몇 번까지 수정할 수 있나요?**
수정 회차와 일정은 품목과 사양에 따라 달라 견적 시 PM이 함께 상담합니다.

**Q. 샘플 단계에서 색이 다르게 나오면 어떻게 하나요?**
승인 전에 전달해 주시면 도안과 사양을 조정해 다시 확인합니다. 500개 미만의 소량이 필요하면 자체 소량 제작 쇼핑몰 나도메이커(nadomaker.com)에서 제작할 수 있습니다.

**Q. 샘플 비용은 어떻게 안내하나요?**
샘플과 양산 단가는 사양에 따라 달라지며 견적 시 함께 안내합니다.
